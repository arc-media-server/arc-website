FAQ & support

Get answers before you install, or tell us what happened if something isn’t working.

What do I need to run Arc?

Arc’s Docker image runs on Linux x86-64 and Arm64. Run it on a computer or NAS that can read your media and keep Arc’s data on local storage. Follow the Docker quickstart.

Do I need TMDB or TheTVDB API keys?

You can add and play files without keys using filenames and local artwork. Configure a provider key if you want Arc to look up titles and fetch its metadata or artwork.

Will Arc change my media files?

Arc reads your files. It keeps library data, watch history and settings separately. You can mount media folders read-only in Docker.

Can I try Arc alongside my current server?

Yes. Give Arc its own data folder and, if needed, a different port. Start with a small library of files you already have and mount it read-only.

How does remote access work?

People outside your home need a reachable Arc server address. Configure secure remote access or an HTTPS reverse proxy, then use Arc’s invite flow to share selected libraries.

Which TV apps can I install?

Visit Apps for screenshots and current installation steps. Availability varies by platform while Arc is in alpha.

Which database should I choose?

SQLite is the default and needs no separate database server. PostgreSQL is an option during first-time setup. Existing installations keep their database engine.

Need a hand?

Tell us your Arc version, the device you’re using, and what happened. GitHub issues are public, so keep credentials and private server addresses out of your report.
