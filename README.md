# Arc Media Server website

Static project site. Serve this directory as-is. No dependencies or build step.

```sh
python3 -m http.server 8080
```

The site uses Arc branding from the server repository and screenshots from the server
and client repositories. These product captures contain TMDB artwork. Inter is bundled under the SIL Open Font License.

The privacy page covers the website. App-store submissions require the applicable app
privacy disclosures.
