Website privacy

This page describes the Arc project website.

Visiting the site

The website uses no analytics, advertising, accounts, or forms. It serves its images and fonts with the site. When hosted on GitHub Pages, GitHub processes visitor IP addresses for security. See GitHub’s privacy statement.

External links and support

Links to documentation, downloads and support take you to other services with their own privacy policies. GitHub issues are public. Remove private server addresses, credentials and personal information from anything you post.

Arc Server and the apps

Arc runs on a server you or your host control. This website does not connect to that server or receive your library or watch history.
